# Contribuindo com o Compêndio Claude Code

Obrigado pelo interesse em contribuir! Este projeto é um guia de utilidade pública
sobre como usar a função de código do Claude (Claude Code), organizado por nível
de experiência. Toda ajuda para manter o conteúdo correto, atualizado e didático
é bem-vinda.

## Como contribuir

1. Faça um **fork** deste repositório.
2. Crie uma branch descritiva: `git checkout -b dica/nome-da-mudanca`.
3. Edite ou adicione arquivos dentro de `claude-code-guia/`, seguindo a
   estrutura de níveis já existente (`01-iniciante`, `02-intermediario`,
   `03-avancado-senior`).
4. Verifique suas informações contra a
   [documentação oficial do Claude Code](https://code.claude.com/docs).
5. Abra um **Pull Request** descrevendo a mudança e preencha o checklist do template.

## Diretrizes de conteúdo

- **Precisão em primeiro lugar**: prefira não incluir uma informação a incluir
  algo incorreto ou desatualizado. Cite a fonte quando possível.
- **Didática progressiva**: cada nível deve pressupor o conhecimento do nível
  anterior, sem repetir explicações básicas nos níveis avançados.
- **Exemplos executáveis**: comandos e trechos de código devem poder ser
  copiados e executados sem adaptação (ou com adaptação claramente indicada).
- **Português claro**: escreva em português do Brasil, evitando jargão
  desnecessário; quando usar um termo técnico em inglês, explique-o na
  primeira ocorrência.
- **Um tópico por arquivo**: mantenha os arquivos focados e curtos; prefira
  criar um novo arquivo a inflar um existente.

## Reportando problemas

Use as [Issues](../../issues) para relatar erros técnicos, sugerir novas
dicas ou apontar conteúdo desatualizado. Escolha o template apropriado
(🐛 Erro ou 💡 Sugestão).

## Código de conduta

Seja respeitoso. Este é um espaço de aprendizado coletivo — críticas devem
ser construtivas e focadas no conteúdo, nunca na pessoa.
