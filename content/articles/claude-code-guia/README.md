# 📘 Compêndio Claude Code — do zero ao nível sênior

Guia de utilidade pública sobre como usar a função de código do Claude
(**Claude Code**), organizado em três níveis progressivos. Escrito em
português, pensado para quem está começando a programar e quer aprender a
"codar com um agente de IA" de forma sólida — sem pular etapas.

## Como usar este guia

Siga os níveis em ordem — cada um pressupõe o conhecimento do anterior:

### 🌱 [01 · Iniciante](./01-iniciante/)
Instalação, primeiro login, como o Claude Code enxerga seu projeto,
`CLAUDE.md`, permissões básicas, comandos essenciais e atalhos de teclado.

1. [Instalação e primeiros passos](./01-iniciante/01-instalacao-e-primeiros-passos.md)
2. [CLAUDE.md e contexto](./01-iniciante/02-claude-md-e-contexto.md)
3. [Permissões básicas](./01-iniciante/03-permissoes-basicas.md)
4. [Comandos e atalhos](./01-iniciante/04-comandos-e-atalhos.md)

### 🌿 [02 · Intermediário](./02-intermediario/)
Skills customizadas, configuração persistente de permissões, subagentes,
MCP, modo Plano/checkpoints e o fluxo completo com Git e GitHub.

1. [Skills e comandos customizados](./02-intermediario/01-skills-e-comandos-customizados.md)
2. [settings.json: permissões e variáveis de ambiente](./02-intermediario/02-settings-permissoes-e-variaveis.md)
3. [Subagentes](./02-intermediario/03-subagentes.md)
4. [Servidores MCP](./02-intermediario/04-mcp-servers.md)
5. [Plan mode e checkpoints](./02-intermediario/05-plan-mode-e-checkpoints.md)

## Sobre a precisão do conteúdo

O Claude Code evolui rapidamente. Este guia foi escrito com base na
documentação oficial da Anthropic disponível em **agosto de 2026**, mas
nomes de comandos, flags e formatos de configuração podem mudar em versões
futuras. Sempre que um capítulo trata de um detalhe mais sensível a
mudanças, ele aponta isso explicitamente e recomenda conferir a
[documentação oficial](./recursos/links-oficiais.md).
