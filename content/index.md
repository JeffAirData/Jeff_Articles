## Compêndio Claude Code

O **Compêndio Claude Code** é um guia progressivo (iniciante → intermediário → sênior/avançado)
sobre como usar a função de código do Claude (Claude Code). Está organizado
em níveis e pode ser explorado em `content/articles/claude-code-guia/`.
